## Features

- Ghost mode: no "read", "online" or "typing"
- Deleted messages stay, with their photos and videos
- View-once photos and videos don't disappear
- Save, copy and forward even where it is restricted
- No ads
- Streamer mode
- Local Telegram Premium
- Message shots as pictures
- Approximate registration date in profiles
- Auto-update

And many more, see the full list below.

#### 👻 Privacy

- **Ghost mode**: don't send "read", don't show "online" and "typing", watch stories unseen. One button in the main menu
- **Streamer mode**: the Soulgram window is hidden from OBS, screen recordings and screenshots, and your own phone number can be hidden
- **A warning before opening links** from other people

- **Deleted messages stay** in the chat marked with 🗑️, with their photos and videos, even after a restart

- **Message shot**: select messages and get a nice picture, to the clipboard or to a file
- **"To the beginning"**: jump to the very first message of a chat
- **"Read all"**: all chats of the account with one button
- **"Delete my messages"**: all your messages in a group at once

#### 🧹 No clutter

- **No ads** in channels, bots and search
- **Word filters** hide spam in groups
- **Shadow ban**: messages of chosen people and channels just disappear for you, and they never know

- **Local Telegram Premium**: everything the Telegram server doesn't check works, like an emoji status next to your name (only you see it)

## Installation

### Windows

Download `Soulgram-setup-….exe` from [Releases](https://github.com/soulgram/Soulgram/releases/latest) and run it. Soulgram is installed separately and doesn't interfere with the regular Telegram.

After that it updates itself: when a new version is out, the "Update Soulgram" button appears below the chats list.

### Android and iPhone

- The **Android** version is in development, it is **not available anywhere** yet.
- There will **never be an iPhone** version.

### Building

The Soulgram code is fully open and lives right in this repository. You can check that there is nothing extra inside and build it yourself, see [soulgram/README.md](soulgram/README.md).

## ⚠️ Beware of fakes

The original Soulgram is **only on this GitHub account**. If you see Soulgram for Android or iPhone somewhere, it is a scam, most likely with a virus. Don't download it.
